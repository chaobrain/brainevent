  仅 Tile 1 的缓冲、标记、索引和标签为橙色，其他两份为灰色。
  活动行列表整体下移，代表 `(b4,1)` 的 warps 块放在列表上方，指向 W 的 Tile 1。
- 右侧保留 `Y^T`，仅 `b4` 列的 `c6:c11` 写入区间为橙色，其余元素均为灰色。
  只保留 Tile 1 shared 向量发起的写入连线，用带箭头的直角线连接对应区间。
  图面仅标结构、维度、索引；解释写在注释和 SVG 描述中。

## 实现语义

依据 `tile_mm/bn_tile_kernels.cuh`：Kernel 1–3 为每个 batch 计数、扫描并写出
有序活动行号；Kernel 4 的每个 block 使用 512 线程、16 个 warp、每行 16 线程，
将权重按目标列原子累加到本 block 的 shared 输出缓冲，最后写回唯一输出区间。
六个示意列代表计算 tile 宽度 U；float32 为 8192，float64 为 4096。
绘图的十八列只是结构示意，不据此断言真实实现会将 n=18 分为三个 tile。

## 验收与边界

- 编译无 warning / overfull / underfull；SVG 自包含、纯矢量，文字在画布内。
- 检查每个 batch 的活动行列表与事件列完全一致，计数限定有效前缀。
- 检查 W、三个 shared 向量与输出区间的列索引连续且一一对应；保留所有源行。
- 核对跨行同列贡献的 shared 累加、空槽、不同 batch 的活动行重合与隔离。
- 建议数值边界用例：全静默 batch、全活动 batch、空稀疏行、同列多贡献、
  尾 tile、float64 半 tile 边界。本次仅修改绘图，不新增或运行 GPU 数值测试。
- 遵循本地 `dev/agent.md`：直接生成 SVG，不启动预览，不提交 Git。
  运行渲染脚本结构检查及差异空白检查；Python 覆盖率和 mypy 不适用本次图稿变更。

# dt0.1 参考结果脑区折线及 D 对比

用户要求对 `ref/n0.25_T10000_burn5000_seed20260926_20261024-195643`
绘制与 D/result/area_rate_timeseries 相同的图，并进行对比。当前分支mm-optimizing。

## 数据和口径

参考模拟dt=.1 ms、总10 s、预热5 s；保存的population_bin_counts本身是1 ms箱，
不可再乘/除10或把10万个模拟步误认成10万个毫秒箱。D为dt=1 ms、总20 s、预热10 s。
参考模型快照在model_snapshot，记录在forward/simulation。复用D的计数归一化和绘图风格，
在新参考scripts中适配路径、dt及标题，保留D已有脚本和图文件。

32脑区全E/I计数除以神经元数及箱宽，导出完整1 ms、100 ms率CSV/NPZ，
灰色1 ms折线、蓝色100 ms不重叠平均，线性坐标，标出5 s预热结束。
参考所有脑区总览采用D已有总览的相同纵轴范围（经核验能容纳全部参考数据），
横轴保留真实0–10 s，不把参考记录延长或拉伸至20 s。各脑区另存单图。
输出位于参考目录forward/area_rate_timeseries，包含PNG/PDF/SVG总览。

## 对比

在其comparison_with_D子目录绘制预热后前5 s叠加图：参考(5,10] s、D(10,15] s，
横轴为各自预热结束后的秒数，均采用相同1 ms计数与100 ms平均。
导出32脑区100 ms趋势叠加总览、1 ms波动叠加总览、单脑区对比及逐区率/CV表。
重算全网与逐区均值及CV，仅作描述性比较；模型参数、延迟和dt不同，
不解释为单独改变dt的因果效果。D额外5秒统计窗不混入这个等时长对比。

## 核验

不同窗口对齐、不等population大小归一化、静默、区域重排与形状不符拒绝。

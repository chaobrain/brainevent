# Hybrid MV 基线测试参数修订

日期：2026-10-14。状态：已按用户确认的方案完成并验证。

## 目标

将 `brainevent/_tcsr/dev/new_mv_operator/benchmark` 的测试空间和计时设置统一为标准 1.1。旧组合的结果已全部删除，只保留 1.1。

所有更新在当前工作分支 `mm-optimizing` 完成。

## 新测试空间

沿用已有标准的尺寸单位 `k=1000`，用户的 `gin i0 0.4` 解释为 Gini 取值 `0、0.4`。

| 参数 | 新值 |
| --- | --- |
| 方阵边长 N | 10,000；100,000；1,000,000；2,000,000 |
| 结构密度 d | 1e-4；1e-3；1e-2 |
| 行长 Gini | 0；0.4 |
| event rate | 1e-4；1e-3 |
| 数据 seed | 固定为 0，仅用于复现，不作为重复维度 |
| 预热调用 | 100 次 |
| 正式计时调用 | 100 次，一次连续测量，不做 round 重复 |

共 24 个结构组合，每个结构分别使用两个活动率，每个变体共 48 条运行记录。活动行数沿用 `floor(event_rate * N + 0.5)`。结构编号由参数网格生成，运行记录使用结构编号与活动率区分；manifest 标准版本为 1.1。

## 实施范围

1. 更新 `benchmark/run.py` 的参数网格和枚举，活动率成为遍历维度，固定单个 seed；删除多 seed 与 rounds 的命令行配置及循环。保留预热和正式调用次数选项，默认均为 100。
2. `_run_case` 使用当前记录中的活动率生成事件。正式调用 100 次后同步，保存总耗时及平均每次 `jax_call_ms`，去掉多轮样本与中位数、最小值、最大值的统计字段。
3. 同步 manifest 配置、日志输出、benchmark README 和测试标准；本规格记录 1.1 口径。
4. 更新同目录 `run_test.py`，检查网格、活动率分组、计时次数、资源预检、不可实现分布、输出记录和命令行参数。保持 JAX >=0.8.0 支持。

本次修改完成后执行针对性验证；启动新的完整基线属于后续运行操作。

## 边界与验证

- `N=10k、d=1e-4、Gini=0.4` 仍不满足当前正行长生成器约束，在两个活动率下均保留不可实现记录：共 2 项，其他 46 项进入资源预检。
- 活动率 1e-4 和 1e-3 在最小尺寸分别产生 1 和 10 个活动行；验证每个活动率实际用于生成及结果记录。
- 大矩阵保持精确 nnz 和 int64 指针规则；内存不足时在分配前标记跳过，最大组合 nnz 为 40,000,000,000。
- 验证每个可运行用例的正式计时仅包含一次由 100 次调用组成的批次，预热 100 次；计时外保留首次编译及前后完整正确性检查。
- 检查 manifest 与 JSONL 均为 48 项、不重复 seed 或 round、输出目录拒绝覆盖、中断状态和失败状态仍被保存。
- 运行相邻 baseline/runner 测试、覆盖率和 mypy；实现覆盖率要求大于 90%，mypy 无错误。记录实际验证的 JAX 版本，不能以当前版本通过代替最低版本验证。

## 实现与验证结果

实现及测试更新位于 `benchmark/run.py` 和相邻的 `run_test.py`，说明同步到 `benchmark/README.md` 及 `benchmark/测试标准/README.md`。未修改算子实现。

- 默认网格为 48 条记录，固定 seed=0。`--event-rates` 支持筛选活动率，兼容 `--event-rate` 别名；重复给出的活动率只执行一次。已移除 `--seeds`、`--rounds`。
- 计时记录为正式调用总耗时 `jax_total_ms` 和平均单次耗时 `jax_call_ms`；保留实际 warmup、repeat。测试验证默认总调用数为 201：计时外首次正确性调用 1 次、预热 100 次、正式调用 100 次。
- 2026-10-14，在物理 GPU 3、JAX/jaxlib 0.11.0 下，`baseline_test.py` 和 `benchmark/run_test.py` 共 54 项测试通过，无跳过。Python 实现总覆盖率 99.56%，其中 runner 为 99.46%，baseline 为 100%。覆盖率文件写入 `/tmp/brainevent-mv-grid-revision.coverage`。
- 使用现有 `/tmp/brainevent-mv-jax080` 依赖，通过 `PYTHONPATH` 验证 JAX/jaxlib 0.8.0；同一组 54 项真实 GPU 测试通过，无跳过。较新版本 CUDA 插件的兼容性警告与此前最低版本验证一致，实际使用匹配的插件完成运行。
- baseline、runner 及各自相邻测试共四个 Python 文件通过 mypy。CLI `--help` 与 `git diff --check` 通过。
- 本次只执行单元及回归验证，未启动新的完整性能基线。测试期间 GPU 3 有其他计算进程，因此测试耗时不作为正式性能结果。

后续正式运行建议先执行 10k 子集，核对两种活动率的记录及不可实现状态，再执行完整清单。为避免参数修改后文档或结果统计仍沿用旧数量，测试明确校验完整参数笛卡尔积、唯一记录数、manifest 配置以及实际调用次数。

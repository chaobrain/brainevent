# CoCoMac 全脑区、全群体均匀抽样 raster

## 范围

在 mm-optimizing 工作分支新增独立绘图脚本，不运行模拟，不修改原始数据。
覆盖用户指定的 7 个目录；“对照_原始参数”包含两次运行，分别输出，共 8 套。
脚本与同级 `_test.py` 放在 `brainevent/_tcsr/dev/cocomac/plot/`。
批次配置、核验记录、使用说明放在 `dev/raster_uniform_20261024/`。

## 抽样与时间

- 用户选择按群体规模同比例抽样，全脑恰好 5000 个神经元；各群体配额采用
  最大余数法，并要求每个真实存在的群体至少保留 1 个。
- 对群体内编号的 k 个等宽区间取中心：`floor((2*j+1)*N/(2*k))`。
- 包含静默神经元，不依据放电量选择；固定同一份编号用于全部案例。
- 脚本另支持可选的每群体固定数量；本次批量明确使用 `--total 5000`。
- 极小群体的强制最少 1 个约束若造成超额，优先从超出理想配额最多的群体回收，
  不允许任何群体减至 0；本批次无需触发该回收逻辑。
- 必须验证 8 套模型的群体顺序与规模一致后，才能声明相同编号可比。
- 读取每份 config 的 dt、duration、burn-in；原始事件时间为 `step*dt_ms`。
- 全程图覆盖 `(0, duration]`，保留并标出预热。
- 放大图取 `(burn_in, burn_in+500 ms]`，横轴为预热结束后的毫秒。
- 这是离散 spike raster，无平滑、放电率分箱或对数坐标。

## 输出

每份运行的 `result/population_raster_uniform/`（dt0.1 案例为
`forward/population_raster_uniform/`；原始参数位于各自运行子目录）保存：

1. 全脑区全程与放大总览，各 PNG/SVG/PDF；32 面板，群体分段和标签。
2. `per_area/` 下 32 张 PNG/SVG，每图左侧全程、右侧放大，每行一个群体。
3. `sampled_neurons.csv`、`population_sampling.csv`、`sampled_spikes.npz`。
4. `metadata.json`、`说明.txt`、包含所有产物哈希的 `manifest.json`。

蓝色为 E、橙色为 I，纵轴是抽样神经元行号，不能解释为 Hz。
SVG/PDF 保留矢量文字坐标，密集事件层栅格化以控制文件大小。
全程缩略图会合并视觉上相邻的事件；查看精细同步结构须使用放大图。
同一神经元编号仅保证位置对应，不意味着不同运行的 spike 应逐一配对。

## 核验与边界

- 录制完成标记、dt、总步数、chunk 连续覆盖、文件名和事件范围合法。
- 每个群体原始 spike 总数、预热后总数与 statistics.npz 相符。
- 验证抽样唯一、落在群体范围、间距相差最多 1、静默行保留。
- 覆盖 dt0.1、dt1、首末步、预热边界、零事件、小群体、无 4E/4I 脑区。
- 损坏索引、非法 neuron ID、不同群体表、错误统计须拒绝。
- sibling pytest 测试 >90% 语句覆盖率；mypy 无错误。
- 独立 NumPy/Matplotlib 工具不导入 JAX，不新增 JAX 版本约束。
- 实际 8 份数据跑完后核对相同抽样、全部 32 脑区与 254 群体输出及哈希，
  并目视检查全程、放大和单脑区图。

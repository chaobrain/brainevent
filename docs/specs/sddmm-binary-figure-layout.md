# Binary SDDMM 图布局修订

- 在当前 `mm-optimizing` 工作分支修改可编辑 TeX、渲染脚本和 SVG。
- Kernel 1：Events `E^T` 改为竖向，显示十个源行与四个 batch 列；
  mask 及其 bit 展开同步竖排，位压缩示例放在 Event 和 mask 中间。
  保留 r4 的活动 batch b1、b3，低四位为 `1010`，压缩字为 `0x0000000A`。
- Kernel 2：去掉 warp 和 W 行副本；mask 竖放在 W 左侧，展开 batch 列紧凑排列，
  r4 的路径指向 W 的 r4 行。ct 位于 W 上方，十个目标列严格对齐；
  W[r4,c4] 向上指向 ct 的 c4 列，突出 ct[b1,c4] 与 ct[b3,c4]。
- mask r4 的四个展开 bit 用一个橙色虚线框圈出，ct c4 的四个 batch 用一个
  橙色实线框圈出；虚线只连接两个框，表达区域对应，不逐个连接小块元素。
  两条映射线直接倾斜连接：r4 框的左上角、右上角分别连接 c4 框的左上角、右下角，
  不设折点，其余数据路径保留原有形式。
  保留私有累加标量与 dW[r4,c4] 的输出路径。
- 压缩整体高度：收紧画布、Kernel 外框及面板间的竖向留白，去除 Kernel 1
  引用图下方空白；ct 靠近 W，ct 标题移到其右侧，W 标题移至列采样箭头左侧。
  网格保持原尺寸；两条倾斜虚线保持原角点对应，输出与累加路径随结构一起调整。
- 核对源行、batch、目标列的索引与活动值；编译无告警，SVG 纯矢量、无外部依赖，
  标签无越界；对矩阵方向、列对齐、Kernel 2 无 warp、框到框映射作结构回归检查。
  遵循 `dev/agent.md`，直接生成 SVG，不启动预览、不提交 Git。
- 边界检查包括 b0/b3 与 r0/r9、零 bit 未高亮、恰好两个活动 ct 元素以及
  箭头端点处于目标边界。仅改图稿，不涉及 JAX、GPU 数值代码、mypy 或覆盖率指标。
- 根据本轮纠正，后续先明确连接表示框级区域对应还是逐元素对应，再绘制连线，
  避免把区域映射画成逐元素配对。

  LaTeX 无告警，SVG 无位图、外部资源或字体依赖。

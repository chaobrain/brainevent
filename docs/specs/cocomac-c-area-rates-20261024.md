# C 全程脑区放电率及 dt0.1 参考对照

用户要求给C也绘制与D及参考结果相同的一套。当前分支mm-optimizing。
复用已经验证的D全程绘图与参考等窗口对照脚本，在C/scripts下存放独立适配版本。
不改原仿真、D、参考或已有C分析文件；新产物位于C/result/area_rate_timeseries。

## 产物和口径

- 32脑区0–20秒全程，包含0–10秒预热，1 ms灰线与100 ms非重叠平均蓝线。
- 两类总览（1 ms＋100 ms、仅100 ms）各提供PNG/PDF/SVG；32个单脑区双面板PNG。
- 完整1 ms、100 ms CSV/NPZ，率由全部E/I计数除以各区神经元数与箱宽得到。
- 新建comparison_with_reference：同一dt0.1参考的(5,10]秒对C的(10,15]秒，
  横轴均为预热后经过时间。两类32脑区叠加总览、32个上下对照及数值表。
- 所有坐标线性；每张总览的32脑区共享纵轴；配对图两条件共享纵轴。
  C的100 ms峰值高于D原图纵轴上限，因此C全程图按实际数据设置上限，不截掉峰值。
- 参考与C的dt、延迟和权重同时不同，只报告描述性差异，不称为单独dt消融。

## 核验与归档

沿用同目录后缀测试，验证加权率、静默、箱边界、尾箱、非法参数、区域重排、
各自预热边界和同长窗口。mypy检查4个新增脚本，行覆盖>90%，抽查成图。
核对全部91,347,662个spike与统计期45,598,645个spike，逐脑区率与原归档一致。
保存来源、参数、图、数值及验证日志，更新C文件清单和CD归档核验；保留原仿真覆盖率口径。

## 完成

生成两类32脑区全程总览和32个单图，以及两类参考叠加总览和32个上下对照。
每种总览保存PNG/PDF/SVG；完整和对比数值另存CSV/NPZ。

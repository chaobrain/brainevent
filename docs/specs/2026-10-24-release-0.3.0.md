## 2. Version

`0.3.0` (minor): the activity contract changes observable results for negative
and NaN events, and #198 changes gradients for non-boolean events. Both are
documented as breaking in `changelog.md`.

## 3. Release checklist (maintainer)

1. Merge the stacked PRs in order.
2. The release date (2026-10-24) is set and `v0.3.0` is tagged on the
   release branch head; if the PRs are squash- or rebase-merged, move the tag
   to the resulting main commit before publishing.
3. Publish the GitHub release for `v0.3.0` (runs `.github/workflows/Publish.yml`).
4. Comment on #198–#204 with the fixing PR; brainpy.state may then raise its
   brainevent floor to 0.3.0 and drop its workarounds.

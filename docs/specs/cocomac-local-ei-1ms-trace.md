## 延迟输入

已排序 CSR 的原 2 ms 段同时含本地 E 和跨脑区边。利用脑区神经元编号
连续、段内目标编号有序，将该段解释为“本地脑区之前 / 本地 / 之后”三个
连续子段，内核延迟分别为 1 / 0 / 1 步。原其他段保持不变。

运行时十段的内核偏移为 `[0,1,0,1,2,3,4,5,6,7] * N`。这只是对已有
CSR 的段描述；既不改变边顺序，也不新增物理延迟类型。重新计算行任务数
和容量，使用显式输入 binary 的契约。保存本次实际使用的 count、offset、
row_task_count 以及有效 population 延迟表，避免仅引用原八段 metadata
而丢失本次覆盖条件。

校验本地 E 改变 1,409,962,678 条边，跨脑区 2 ms 保留 46,583,642 条；
逐行段计数之和等于行长。正式模拟前，用完整 CSR 和独立 NumPy 参考检查
稀疏事件的投射、队列剩余量和两次回绕，然后重置全部物理及队列状态。

  沿用原 Hybrid SpMV 图的短行 TPR、长行任务队列、CUDA block 和橙蓝路径。
- 闭环示例采用 N=10、D=3，W 为 10×10；源行及目标列均按 0:3、4:7、8:9
  划分脑区。选中源脑区的投射示例中，目标 P0/P1/P2 对应延迟类型 0/1/2。

- 展示 head=0：目标 c0:c3 → slot 0，c4:c7 → slot 1，c8:c9 → slot 2。
  输出以目标列号和时间槽共同寻址；同一输出格的重合贡献使用橙蓝三角标记。
- 短行 r2 的 c2/c7 分别写入 slot 0/1；长行 r7 按投射段拆成三项任务：
  c0,c1,c3 / c4,c6,c7 / c8,c9，队列增加 task_out_off=0/N/2N。
  不允许一个任务跨越不同投射延迟。任务槽位和真实行长仅作示意。

  最大延迟为 D-1，剩余时间槽保留其未来贡献。

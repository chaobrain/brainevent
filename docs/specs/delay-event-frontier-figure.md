# Delay 事件压缩与步进前沿示意图

- 在当前 `mm-optimizing` 工作分支新增
  `brainevent/_tcsr/dev/with_delay/fig/delay_event_frontier.tex`、
  `render_delay_event_frontier.sh` 和自包含矢量 SVG。
- 从左到右展示事件缓冲、前沿列向量、按列划分 delay 的权重矩阵，
  和三列结果矩阵 Y。示例采用 `neuron=8`、`n_delay=3`、当前列 `k=1`。
- 事件缓冲保留完整 `neuron × n_delay` 外框；每行有效格从左边框开始，
  等宽、相邻、无间距，保存升序的原始列号。未使用尾部不画伪事件格。
  保留神经元行号，不把压缩槽位置误当成原始列号。
- 示例行列表依次为 `[0,1]`、`[2]`、`[]`、`[1,2]`、
  `[0,1,2]`、`[0,2]`、`[2]`、`[1]`。
  高亮值等于 1 的格子，得到前沿 `[1,0,0,1,1,0,0,1]`；
  抽取前后行对齐，压缩位置不同不影响列号匹配。
- 权重矩阵的行表示源神经元、列表示目标神经元；前沿活动行对应
  权重的活动行。W 的 `c0:c2`、`c3:c4`、`c5:c7` 分属 delay 0、1、2，
  分别使用橙色、蓝色和深灰色；列边界、组标题和结果列使用相同颜色。
  前沿使用中性深灰色，避免把当前事件列 k 与投射 delay d 混淆。
  三份贡献分别为 `Y[:,d] = W_d.T @ x_k`，W_d 只保留本组权重。
  结果行保留全局目标编号 c，结果列是 delay 类型 d；不把目标编号
  重新从零编号，也不把三类贡献折叠到同一列。
  权重非零元及非零结果用方块标记，只表达位置，不表达幅值。
  示例权重取正值，以便根据活动行的目标并集核对结果支持集。
- 结果坐标为 `(c0,d0),(c1,d0),(c2,d0),(c4,d1),(c5,d2),(c7,d2)`；
  `c3,c6` 和所有非所属 delay 格保持空白。每个 W 列组用一条有向折线
  连接其 Y 列底部；交叉处留白断开，避免误读为汇合点。
  这表示当前前沿产生的、按 delay 类型组织的贡献，不暗自引入 `(k+d)%3`
  物理环形地址。图面不定义跨步存量、消费、清零或闭环更新顺序。
  图面只标结构、维度和索引；公式、示例约定放在源码注释和 SVG 描述中。
- 沿用现有配色；采用同样大小的方格与直角连接线。
  按本地绘图约定直接输出 SVG，不启动预览，不提交 Git。

## 验收与边界

- 编译无 LaTeX warning、overfull 或 underfull；文字均在画布内，
  SVG 纯矢量、字形转路径、无外部资源。
- 校验各行压缩槽连续且从零开始、列号合法且不重复、前沿按值匹配，
  核对权重活动行、列类型及输出的 `(目标,delay)` 坐标；检查文字包围盒与连线避免遮挡。
- 边界包括空事件行、不含 k、k 位于不同压缩槽、原始列 0 和 2、
  W 列类型边界 c2/c3、c4/c5、首末目标 c0/c7、
  多条活动行贡献同一目标、仅非活动行连接的输出目标。
  建议扩展验证全静默、全活动、k 在首末列及最后一列回绕；本图不定义
  环形缓冲的读写/清零调度，不修改数值算子或 JAX 依赖。
- 无新增 Python 模块，Python 单元测试覆盖率及 mypy 不适用于本次图稿；
  验证采用渲染脚本内的数据不变量、成品 SVG 和 PDF 文本边界检查。
